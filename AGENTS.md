# AGENTS.md

One-bit watch faces for the Garmin Instinct 3 Solar 45mm (`instinct3solar45mm`, 176x176, Connect IQ API 5+), written in Monkey C, plus a static gallery that runs the original HTML designs live.

## Layout

| Path | What |
|---|---|
| `design/<Name>.dc.html` | Original interactive design: SVG template with `{{holes}}` and a `Component extends DCLogic` script. Source of truth, read-only. |
| `refs/<Name>.png` | The design rendered at 1 bit, 3x. Generated by `tools/ref.py`, read-only. |
| `faces/<Name>/` | The port: `face.json`, `source/View.mc`, `art/*.svg`. |
| `core/source/` | Shared Monkey C: `BaseFace`, `Now`, `U`, `G` (Base.mc) and `D` data sources (Data.mc). |
| `previews/<Name>.png` | Awake and asleep frames from the simulator, used by the gallery. |
| `tools/` | Python, standard library only: `build.py`, `shot.py`, `check.py`, `gallery.py`, `ref.py`, `strip_design.py`, `sheet.py`, `mcp_server.py`. |
| `site/` | Gallery front end (vanilla JS). `tools/gallery.py` assembles it with data into `_site/`. |
| `docs/PORTING.md` | Rules for porting a design: read before touching `faces/` or `core/`. |

Generated and ignored: `build/`, `dist/`, `_site/`, `.keys/`, `picked/`, `.work/`.

## Commands

```bash
python3 tools/check.py                  # static checks, no SDK needed
uvx pytest                              # unit tests
uvx ruff check . && uvx ruff format --check .
npm ci && npm run lint                  # eslint and prettier for site/
python3 tools/gallery.py                   # gallery into _site/, serve with python3 -m http.server -d _site
python3 tools/build.py <Name>|--all     # needs the Connect IQ SDK and chrome-headless-shell
python3 tools/shot.py <Name>            # macOS only: simulator run, prints ok/FAIL and writes build/shots/<Name>.cmp.png
```

`pre-commit install` runs the same checks on commit.

## Rules

- Monkey C: no comments, ASCII outside string literals, never `COLOR_BLACK`/`COLOR_WHITE` (use `G.ink`/`G.paper`; the build generates dark variants). Every `View.mc` declares `class FaceView extends BaseFace`.
- Faces draw a complete frame from state in `render`; asleep frames must look finished. Respect the CPU, memory and partial-update budgets in `docs/PORTING.md`.
- Real watch data over the design's sample numbers. If something cannot be real, keep it and describe it in `face.json` `fake`.
- Python: standard library only in `tools/` (except `mcp_server.py`, which declares its deps inline), ruff-clean, line length 120.
- Changes to `core/` or `tools/build.py` affect every face: rebuild all faces and compare `shasum dist/*.prg` before and after. Builds are deterministic.
- Never commit `.keys/` or any `*.der`/`*.pem`. `tools/build.py` generates a local developer key when it is missing.
- Do not edit `design/` or `refs/`. A design change is a new design file.

## Skills and MCP

- Skills live in `.agents/skills/` (`.claude/skills` links there): `port-face`, `check-face`, `release`, `install-face`.
- `.mcp.json` registers `tools/mcp_server.py` (stdio, run by `uv`): `list_faces`, `face_info`, `read_design`, `check_faces`, `build_face`, `shoot_face`, `build_site`.

## CI

`.github/workflows/ci.yml` runs lint, checks, tests, the MCP smoke test and a gallery build. It does not compile faces: the Connect IQ SDK and device files require a Garmin developer login and may not be redistributed. `pages.yml` deploys the gallery from `main`. Releases are built locally, see the `release` skill.
